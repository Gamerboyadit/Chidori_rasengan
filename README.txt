NARUTO SURiken CHIDORI

Put naruto.mp4 and sasuke.mp4 inside the assets folder.

To run with camera:
1. Open a terminal in this project folder.
2. Run: python -m http.server 8765
3. Open: http://localhost:8765/Suriken_chidori.html
4. Allow camera permission.

Internet is required for the MediaPipe CDN scripts.
